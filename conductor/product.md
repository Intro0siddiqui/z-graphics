# Initial Concept
Zawra Browser graphics abstraction layer.

# Product Definition: z-graphics RHI

## Vision
To provide a high-performance, platform-agnostic Render Hardware Interface (RHI) that enables the Zawra Browser (and other potential consumers) to render complex web content efficiently across diverse graphics APIs.

## Target Audience
- **Browser Engine Developers:** Need efficient, zero-copy compositing capabilities.
- **External RHI Users:** Require a stable, cross-platform graphics abstraction for native applications.
- **Library Maintainers:** Focused on long-term API stability and cross-platform backend maintenance.

## Goals
- **High Performance:** Minimize CPU overhead and maximize GPU utilization through a zero-copy architecture.
- **Cross-Platform Parity:** Provide a unified, consistent API surface that abstracts the complexities of Vulkan, Metal, and D3D12.
- **Safe FFI Surface:** Expose a clean, predictable, and safe FFI API for seamless integration with C++ browser engines like WebKit.

## Key Technical Features
- **Native Swapchain:** Full ownership of the presentation lifecycle for windowed applications.
- **Texture/DMA-BUF Support:** Efficient, zero-copy texture uploading and cross-process buffer sharing via DMA-BUF.
- **HLSL/SPIR-V Pipeline:** Unified shader authorship in HLSL with cross-compilation targets for all backends.

## Critical Requirements
- **Latency Focused:** Engineered for sub-millisecond frame preparation time.
- **Memory Optimized:** Stringent control over GPU memory allocation and footprint to support constrained environments.

## Strategic Technical Requirements
- **Full DMA-BUF/FD Pipeline:** Implement import functionality on the WebProcess side, not just FD export from the UI process.
- **Multi-Layer Compositing:** Move beyond a simple fullscreen quad to support texture sampling and true multi-layer web compositing.
- **YUV Format Support:** Native hardware-accelerated color space conversion for direct video decoding support.
- **Dynamic Shader Management:** Implement a shader registry/loader capable of managing arbitrary shaders generated by WebKit.
- **Process Residency Model:** Refactor the RHI lifecycle to enable `z-graphics` instances to live within the WebProcess, providing secure GPU access per-tab.
- **Layer Tree IPC:** Implement IPC to pass complete, composited layer trees rather than raw File Descriptors, enabling advanced GPU-accelerated compositing.
